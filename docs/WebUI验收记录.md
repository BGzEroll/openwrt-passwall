# WebUI 操作验收

本轮针对固定 ImmortalWrt 23.05、Xray 1.8.23 环境，使用真实浏览器操作原生 LuCI 页面；保存、应用、增删、测速、规则更新均通过 WebUI 提交。SSH 用于部署、夹具、运行取证、故障注入和现场恢复，不代替被测表单操作。验收期间，主路由只读检查并承载少量真实流量；验收后按用户要求部署，结果见末节。全过程未断开 WAN。

此前“全新安装通过”的记录没有覆盖真实 GUI 新建并保存节点，因而漏掉固定类型字段未落盘。这是验收遗漏，旧记录不能作为该路径已通过的证据。本轮重新从初始化配置执行实际浏览器操作。

## 发现并修复的问题

| 问题 | 修复及回归 |
| --- | --- |
| 新节点缺少 `type=Xray`，保存失败 | 创建时写入固定类型，保存前补齐旧节点；空配置新增、Save、应用、重开和旧节点修复通过 |
| 修改 Hosts 后 dnsmasq 未加载新内容 | Hosts 内容纳入重载判断；GUI 添加、删除后实际查询核对 |
| HTTP 节点 TLS/socket 设置未进入核心配置 | 补齐 streamSettings；明文/TLS 均完成真实 HTTPS |
| 连续更新时 CGI 报 `Interrupted system call`、LuCI 500 | 使用原生同步命令执行和匿名文件捕获输出；20 次 GUI 更新与状态轮询通过 |
| 非法端口和混合有效/无效文件字段可能部分写入 | 统一端口校验及区间合并；文件推迟到整表校验通过后写入，失败保留输入及原文件 |
| 嗅探排除列表无法清空 | 区分清空和隐藏；清空、关闭保留、重新启用通过 |
| 未选择 TCP/UDP 节点时 DNS 不启动 | 启用插件即启动所需 DNS；独立 Xray DNS 高级参数参与重载签名 |
| 应用失败缺少页面反馈 | 原生警告展示失败原因，成功纠正后清除；无效 PBR 网关保留原运行配置 |
| 并发 URL 测试争用固定端口 | 独立非阻塞锁，第二请求提示稍后重试；实际并发验证 |
| 均衡备用节点无法清空、过期页面接受已删除成员 | 增加“不使用”及成员校验；两页交错编辑/删除后拒绝过期提交 |
| 复制节点意外提交其他页面的 Save 配置 | 复制只保存待应用变更；Save 后复制不再提前提交 |
| 分流备注中的尖括号被当成 HTML | 转义链接标题，合法标点按原文显示 |
| 系统 tcping 不支持 IPv6 | IPv6 字面量使用原生非阻塞 socket 探测；裸地址及括号地址的 Ping/TCP/URL 测试通过 |

另清理删除规则的前置代理标记，隐藏 WireGuard 不使用的 TCP socket 开关。本机代理默认开启，启动延迟默认 0；已有明确配置不覆盖。
